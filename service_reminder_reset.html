Service reminder reset (oil change and inspection) with VCDS

Reset the oil-change and inspection reminders in the instrument cluster with VCDS.

Tools needed
  • VCDS

Quick method (SRI Reset)

  1. Connect VCDS
    Use the car's OBD-II port.
  2. Turn on the ignition
    Leave the engine off.
  3. Open the instruments module
    In VCDS, select Control Module → 17 – Instruments.
  4. Open Adaptation
    Select Adaptation – 10.
  5. Run SRI Reset
    Click SRI Reset and select Oil Change Service or Inspection Service. Run both if you did both.

Manual method (if SRI Reset doesn't work)

In Adaptation, set each channel to 0, one at a time, using Test and then Save.

  • Oil change: channel 40 (distance since service) and 41 (time since service).
  • Inspection: channel 53 (distance since inspection) and 55 (time since inspection).

Note: Don't change channels 42–52. They set the service interval itself, not the counters. This car is coded for fixed intervals: 15,000 km or 365 days for oil changes, and 30,000 km or 730 days for inspections.

Results: Cycle the ignition and check that the instrument cluster shows a new service interval.
