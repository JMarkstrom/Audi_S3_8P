Audi S3 8P

Magnetic Ride (Magride) troubleshooting

Checks for the magnetic-ride dampers, from a road test through VCDS current readings.

Tools needed
  • VCDS (optional)

Introduction

Some Audi S3 8P models, including mine, came from the factory with Audi magnetic ride ("Magride"). Instead of conventional valving, each damper is filled with a magnetorheological fluid whose stiffness changes when an electric current runs through a coil inside the damper. The driver selects between Normal and Sport mode with a button on the center console. Sport gives noticeably(!) firmer damping. Ride height stays the same.

When it works, Magride is a great feature. Unfortunately, many owners report that the dampers wear out relatively early, and replacements are expensive. This guide shows how to check the health of a Magride system with VCDS and simple tests, so you can decide on facts whether your dampers actually need replacing.

As for replacement: after researching the options, I concluded that the best solution for my car was to fit coilovers and use a Magride cancellation kit (emulator) so the system stays fault-free. Your conclusion may differ depending on budget, use and whether you want to keep the factory functionality.

Quick test without VCDS #1

  1. Drive the car
    Preferably on a bumpy or twisty road.
  2. Press the damping button
    The button is between the seats. LED off is Comfort (standard). LED on is Sport.

Results: The car should firm up noticeably within a moment of engaging Sport mode.

Quick test without VCDS #2

  1. Turn on the ignition
    The engine does not need to run.
  2. Press and hold the damping button
    Hold it for more than 5 seconds. The LED flashes when test mode is active.
  3. Push down on each corner
    Assess the damping response. Compare each corner with test mode on vs off.
  4. Exit test mode
    Press the button again, switch off the ignition, or drive above 10 km/h.

Results: Each corner should rebound noticeably slower and firmer with test mode on than with it off.

Output Tests (best electrical check)

  1. Connect VCDS
    Use the car's OBD-II port.
  2. Turn on the ignition
  3. Open the suspension module
    In VCDS, select Control Module → 14 – Susp. Elect.
  4. Run an output test
    Select Output Tests / Final Control Diagnosis and activate one damper at a time.
  5. Push down on the activated corner
    It should firm up.
  6. End the test
    Activation ends via VCDS or by cycling the ignition.

Results: Successful activation shows approx. 2,000 mA for the activated damper (SSP381: 2 A).

Reading mode and current in VCDS

  1. Connect VCDS
    Use the car's OBD-II port.
  2. Start the engine
  3. Open the suspension module
    In VCDS, select Control Module → 14 – Susp. Elect.
  4. Open Measuring Blocks – 08
    028 shows calculated damper and control unit temperatures. Then browse 001–030 and look for fields showing system status, button position (E387), Sport/Comfort, or coil current for N336–N339.
  5. Open Adv. Meas. Values
    Select anything resembling system status, damping mode, or button E387; current for FL, FR, RL, and RR (N336–N339); and ride height or level senders.
  6. Log while driving
    Toggle Sport on and off and drive a short twisty section. Save the CSV.
  7. Compare the four currents
    Compare all four currents in Comfort vs Sport.

Results:

  • All four currents should rise in Sport compared with Comfort.
  • Current varies constantly with road and load, since J250 calculates it individually for each damper.
  • A corner stuck near 0 A, or one that does not follow the mode change, indicates a faulty damper or wiring, sometimes without a fault code.
